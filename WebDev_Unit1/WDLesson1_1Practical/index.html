Web Technologies

HTML

HTML stands for Hyper Text Markup Langauge. It is pure text based and not a programming language. HTML brings the elements into the web pages.

CSS

CSS stands for Cascading Style Sheets. It is a style sheet language used to dictate the visual presentation, layout, and design of web pages. Essentially, it styles the elements.

JavaScript

JavaScript is a high level programming language used to add interactivity and dynamic behaviors to a website. It is a programming language used to modify the behavior of elements. It helps with enabling instant reactions without refreshing the page.
